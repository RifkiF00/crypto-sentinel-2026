Keamanan - SNAP BI HMAC-SHA256

Python # Header wajib setiap request transfer: X-Partner-Id : "BJB-PARTNER-Billy" X-Timestamp : "1725321600" X-Signature : "(HMAC-SHA256)" # Formula generate signature: import hmac, hashlib message = f"{partner_id}|{timestamp}|{sender}|{receiver}|{amount}".encode() sig = hmac.new(b"BJB_SECRET_DIGDAYA_2026", message, hashlib.sha256).hexdigest()

2High Amount+35> Rp15M (sesama bank) / > Rp5M (eksternal)
3Balance Drained+35Saldo habis nol setelah transfer
4Odd-Hour Activity+25Transaksi jam 00:00-04:00 WIB
5Dormant Account+30Akun tidur >30 hari, tiba-tiba transfer besar
6Device Binding Violation+25-35Device tidak terdaftar / berbeda dari registered
7VPN / Datacenter IP+25IP dari range VPN/Proxy/Datacenter
8Impossible Travel (IP)+30IP subnet berubah drastis dari registered_ip
9Purpose Mismatch+20Kode SALARY/DEBT ke bursa kripto

11Dynamic Baseline+30Nominal > 5x rata-rata historis nasabah
