Peta Ekosistem Frontend

Halo Aam! Di sistem Crypto-Sentinel 2026, peran antarmuka pengguna (Frontend & Mobile UI/UX) dibagi menjadi 2 pilar besar:

1. Web Forensic Dashboard (:5173)

Stack: React 19, Vite 5, Recharts, Framer Motion, Lucide Icons.
User: Compliance Officer, Investigasi AML, Regulator Bank.
Fungsi: Memonitor transaksi real-time, grafik keterhubungan mule GNN, audit trail, dan manajemen alert.

2. Mockup Mobile Banking Apps (:8081 & :8082)

Stack: Flutter 3 (Dart), berjalan di Chrome Web & Android.
Apps: Bank bjb DIGI Mobile & Bank Kuningan Mobile.
Fungsi: Simulasi nasabah mentransfer dana asli dengan proteksi SNAP BI HMAC signature dan pop-up pemblokiran fraud.

⚡ Hubungan Frontend dengan Backend:
• Mobile App Flutter mengirim transfer ke expresso-api :8080.
• expresso-api menganalisis risiko ke crypto-sentinel-api :8000.
• Dashboard React (Port 5173) melakukan polling setiap 5 detik dan langsung menampilkan notifikasi fraud + highlight pada grafik GNN!

Fitur UI/UX Unggulan (Selling Point Aam)

🔒 Privacy Masking (UU PDP)

Tombol toggle di Header. Saat diaktifkan, NIK KTP dan No Rekening disensor secara otomatis (e.g. 3171********21) sesuai mandat UU PDP No. 27/2022.

🕸️ Interactive GNN Canvas

Grafik relasi dinamis dengan canvas SVG: Analis dapat mengklik simpul rekening untuk menelusuri aliran uang pencucian tanpa membaca ribuan baris log teks.

👤 Customer 360 Drawer

Slide drawer dari kanan layar saat rekening diklik. Menampilkan skor CRA, riwayat device ID, IP subnet, dan status PEP secara instan tanpa reload halaman.

🔊 Cyber Alert Sound FX

Menggunakan Web Audio API sintetis (tanpa aset file mp3) yang berbunyi secara otomatis saat terdeteksi transaksi High Risk atau serangan Smurfing.

Skenario Live Demo (Panduan Mentoring Aam)
Langkah-Langkah Demo Memukau untuk Aam:

1. Tunjukkan Dashboard (:5173): Buka Dashboard di browser. Jelaskan metrik ringkasan, grafik tren, dan toggle Privacy Masking.

2. Demo Transfer Aman (:8081): Buka Mobile Banking bjb. Kirim Rp 100.000 ke rekening biasa. Tunjukkan transfer BERHASIL seketika.

3. Demo Serangan Fraud & Blokir Otomatis: Di Mobile bjb, coba kirim Rp 60.000.000 ke rekening crypto exchange. Tunjukkan aplikasi mobile langsung memunculkan POP-UP MERAH DIBLOKIR FDS!

4. Tunjukkan Respon Dashboard: Kembali ke Dashboard Web. Perlihatkan alarm suara berbunyi, baris merah baru masuk di tabel transaksi, dan skor risiko 90 tercatat di sistem.

5. Buka Visualisasi GNN: Klik tombol 'Investigasi GNN' pada transaksi merah tersebut untuk menampilkan peta keterhubungan sindikat mule.
